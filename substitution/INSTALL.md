# ติดตั้งระบบจัดสอนแทนบน Google Apps Script

ใช้เวลาประมาณ 15 นาที ทำครั้งเดียว ควรติดตั้งด้วย **บัญชี Google ที่เป็นเจ้าของไฟล์ e-Score** (หรือบัญชีที่มีสิทธิ์เปิดไฟล์ e-Score) เพราะระบบต้องอ่านชีต `Users` ของ e-Score

## 1. สร้างฐานข้อมูลและโปรเจ็กต์
1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น **ระบบจัดสอนแทน KJST 2-2569**
2. เมนู **ส่วนขยาย → Apps Script** แล้วตั้งชื่อโปรเจ็กต์
3. ⚙️ **การตั้งค่าโปรเจ็กต์**: ติ๊ก “แสดงไฟล์ Manifest `appsscript.json` ในเอดิเตอร์” และตั้งเขตเวลาเป็น **(GMT+07:00) Bangkok**

## 2. วางไฟล์ (อยู่ในโฟลเดอร์ `substitution/gas/`)
| ไฟล์ใน repo | สร้างใน Apps Script เป็น |
|---|---|
| `Code.gs` | แทนเนื้อหาไฟล์ `Code.gs` เดิมทั้งหมด |
| `Index.html` | ไฟล์ HTML ชื่อ `Index` |
| `TimetableData.html` | ไฟล์ HTML ชื่อ `TimetableData` (ข้อมูลตารางสอน 2/2569) |
| `appsscript.json` | แทนเนื้อหา `appsscript.json` |

แล้วกด 💾 บันทึก

## 3. รัน `setup`
เลือกฟังก์ชัน **setup** แล้วกด ▶ เรียกใช้ จากนั้นอนุญาตสิทธิ์ (Google จะเตือนว่าแอปยังไม่ได้รับการยืนยัน → ขั้นสูง → ไปยังโปรเจ็กต์)

ระบบจะสร้างชีต `Settings, Teachers, Timetable, ClassTimetable, Duty, Requests, Items, Log, UserMap` และนำเข้าตารางสอนให้

## 4. ตั้งค่าในชีต `Settings`
| key | ใส่อะไร |
|---|---|
| `ESCORE_SPREADSHEET_ID` | ID ของไฟล์ e-Score: ส่วนระหว่าง `/d/` กับ `/edit` ใน URL |
| `ESCORE_USERS_SHEET` | `Users` (ค่าเริ่มต้น) |
| `ACAD_USERS` | ชื่อผู้ใช้ e-Score ของหัวหน้ากลุ่มบริหารงานวิชาการ |
| `ADMIN_USERS` | ชื่อผู้ใช้ e-Score ของผู้ดูแลระบบ (ใส่ของตนเองได้) |

จากนั้นรันฟังก์ชัน **testEscore** แล้วดูที่ “บันทึกการดำเนินการ”
- ควรเห็นคอลัมน์ที่ระบบเลือกใช้ (username / password / ชื่อ) และจำนวนครูที่จับคู่ชื่อได้
- ถ้าเลือกคอลัมน์ผิด ให้กำหนด `ESCORE_COL_USERNAME`, `ESCORE_COL_PASSWORD`, `ESCORE_COL_NAME` เป็นชื่อหัวคอลัมน์ตามจริง
- รหัสผ่านรองรับ ข้อความธรรมดา, SHA-256 (hex/base64) และ MD5 ตรวจให้อัตโนมัติ (`ESCORE_HASH = auto`) — **ถ้า e-Score เข้ารหัสแบบมี salt หรือวิธีอื่น ให้ส่งโค้ดส่วนล็อกอินของ e-Score มาให้ดู จะปรับให้ตรงกัน**

## 5. เผยแพร่เป็นเว็บแอป
**ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
- ดำเนินการในฐานะ: **ฉัน**
- ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (หรือ “ทุกคนในโดเมน kjst.ac.th” ถ้าครูทุกคนใช้บัญชีโรงเรียน)

คัดลอก URL ที่ได้ไปให้ครู — เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่าน e-Score

> เมื่อแก้โค้ดภายหลัง: **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมจะใช้ต่อได้

## 6. ตั้งค่าครั้งแรกในหน้าเว็บ (เมนู ตั้งค่า)
1. เลือก **หัวหน้ากลุ่มสาระการเรียนรู้** ทั้ง 9 กลุ่ม
2. ตรวจตาราง **จับคู่บัญชี e-Score กับรายชื่อครู** — บัญชีที่ขึ้น “ยังไม่กำหนด” ให้เลือกชื่อครูเอง (รวมบัญชีของหัวหน้าวิชาการ ถ้าต้องการให้จัดสอนแทนของตนเองได้ด้วย)
3. ตรวจวันหยุด (ค่าเริ่มต้น: 7, 10, 31 ธ.ค. 69 และ 1 ม.ค. 70 — **เพิ่มวันมาฆบูชา/วันสอบ/กิจกรรมโรงเรียน**)
4. ถ้าต้องการอีเมลแจ้งเตือน: ใส่ `ESCORE_COL_EMAIL` แล้วเปิด “ส่งอีเมลแจ้งเตือน”

## เมื่อตารางสอนเปลี่ยน
เมนู **ตั้งค่า → ตารางสอน → นำเข้าตารางสอนใหม่** แล้วเลือกไฟล์ `Dashboard-…html` (หรือ JSON) ข้อมูลการจัดสอนแทนเดิมไม่หาย (อ้างอิงตามชื่อครู)

## ข้อมูลอยู่ที่ไหน
ทุกอย่างอยู่ใน Google Sheet ที่สร้างในข้อ 1 อ่านได้ด้วยตา:
- `Requests` 1 แถว/คำขอ · `Items` 1 แถว/คาบ (ผู้สอนแทน, รับทราบเมื่อ, เหตุผลขอเปลี่ยน, สถานะ) · `Log` ทุกการกระทำ
- ไม่ควรแก้ชีต `Requests`/`Items` ด้วยมือขณะมีคนใช้งาน (ระบบเขียนทับทั้งชีตทุกครั้งที่บันทึก)
- ไฟล์แนบเก็บในโฟลเดอร์ Drive “ระบบจัดสอนแทน KJST - ไฟล์แนบ” ของผู้ติดตั้ง
